# ISLANDS — мир парящих островов

Браузерная 3D-игра, которую придумывают дети, а пишет ИИ.

## Как играть
Дважды щёлкни **`Запустить игру.bat`**. Откроется браузер с игрой.
(Нужен Node.js: https://nodejs.org — ставится один раз.)

Управление на компьютере:
- **WASD** — идти, **Пробел** — прыжок, **мышь (зажать и тянуть)** — камера, **Esc** — меню
- **E** — действие (собрать ресурс / приручить существо)
- **F** или **клик мышью** — атака
- **1** — способность существа, **P** — панель существ, **B** — строительство
- В режиме строительства: **E** — поставить, **Z** — повернуть, **Q** — отмена
- Команды существу: **X** следуй, **G** стой, **V** защищай, **T** атакуй цель, **R** вернись

На телефоне: джойстик — идти, свайп по экрану — камера, кнопки «Прыжок», «Атака», «Действие», 🐾 — существа.

Языки: русский, English, ქართული — выбираются в главном меню.

## Что есть в версии 0.2 (звук и настройки)
- Домашний остров с деревьями, камнями, кристаллами, домом и порталом.
- Ледяной остров: в него ведёт фиолетовый портал (нажми «Действие» рядом с ним). Там живут ледяные слизни и можно приручить Ледяного лиса за 5 кристаллов. Обратный портал стоит на самом острове.
- Сбор ресурсов (дерево, камень, кристаллы) — они снова вырастают.
- Три дикие существа. Приручение за ресурсы:
  - Огненный лис — 3 кристалла (огненный шар)
  - Каменный страж — 6 камней (защитный щит)
  - Лесной дух — 6 дерева (лечение)
- Спутник идёт за героем, сам помогает в бою и получает опыт.
- Эволюция существ: на 4 и 8 уровнях они становятся крупнее, меняют цвет и имя, а их характеристики растут.
- Слизни-враги, бой, урон на экране, опыт и 10 уровней героя.
- Строительство: платформа, стена, мост, домик, загон. Мосты и платформы можно строить за краем острова. Снос возвращает половину ресурсов.
- Короткое обучение из 5 шагов (можно пропустить).
- Звуки (удары, сбор, приручение, уровень, строительство) — делаются прямо в браузере, файлов не нужно.
- Настройки в главном меню (⚙): звук и громкость, качество графики (Авто / Низкое / Среднее / Высокое), показ FPS. В режиме «Авто» игра сама снижает разрешение, если тормозит.
- Автосохранение (позиция, уровень, ресурсы, существа, постройки, язык).

## Как предложить идею
Напиши ИИ обычными словами: «Добавь дракона, который летает». ИИ изменит игру, а ты проверишь результат.

## Для разработчиков
```
npm install     # один раз
npm run dev     # запуск для разработки
npm run build   # сборка в папку dist (её можно выложить на GitHub Pages / Cloudflare Pages)
```
Папки `src/`: `core` (цикл игры), `world` (остров, ресурсы), `player` (герой, камера, ввод),
`building` (строительство), `creatures` (существа и их поведение), `combat` (враги и бой), `inventory`, `progression`,
`ui` (интерфейс), `save` (сохранения), `config` (данные: существа, враги, ресурсы, тексты).

Новое существо = одна запись в `src/config/creatures.js` + названия в `src/config/i18n.js`.
Новый остров = запись в ISLANDS и PORTALS (src/world/World.js) + враги в ENEMY_SPAWNS.
Новый враг = запись в `src/config/enemies.js`. Все тексты — в `src/config/i18n.js`.
Новый звук = строка в `src/core/Sound.js` и `events.emit('имя')` там, где он нужен.
Новая постройка = запись в `src/config/buildings.js` + названия в `src/config/i18n.js`.
Формат сохранения — версия 3 (старые сохранения читаются).
