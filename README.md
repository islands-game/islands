# ISLANDS — мир парящих островов

Браузерная 3D-игра, которую придумывают дети, а пишет ИИ.

## Как играть
Дважды щёлкни **`Запустить игру.bat`**. Откроется браузер с игрой.
(Нужен Node.js: https://nodejs.org — ставится один раз.)

Управление:
- Компьютер: **WASD** — идти, **Пробел** — прыжок, **мышь (зажать и тянуть)** — камера, **Esc** — меню.
- Телефон: джойстик слева — идти, кнопка справа — прыжок, свайп по экрану — камера.

Языки: русский, English, ქართული — выбираются в главном меню.

## Что уже есть (версия 0.1a)
- Парящий остров: деревья, камни, кристаллы, дом, портал, облака.
- Герой с ходьбой, прыжком и камерой от третьего лица.
- Здоровье, уровень, полоска опыта (пока без источников опыта).
- Автосохранение: позиция, уровень, опыт, язык.

## Что дальше (0.1b и 0.1c)
Сбор ресурсов, приручение существ (огненный лис, каменный страж, лесной дух), враг и бой, строительство.

## Как предложить идею
Напиши ИИ обычными словами: «Добавь дракона, который летает». ИИ изменит игру, а ты проверишь результат.

## Для разработчиков
```
npm install     # один раз
npm run dev     # запуск для разработки
npm run build   # сборка в папку dist (её можно выложить на GitHub Pages / Cloudflare Pages)
```
Папки `src/`: `core` (цикл игры), `world` (остров), `player` (герой, камера, ввод), `ui` (интерфейс),
`save` (сохранения), `config` (тексты и данные). Все тексты — в `src/config/i18n.js`.
