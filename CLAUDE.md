# ISLANDS — правила для ИИ-помощника

Браузерная 3D-игра (Three.js + Vite, без сервера). Её придумывают дети 12–17 лет, ИИ пишет код.
Отвечай по-русски, коротко и понятно подростку.

## Главное
- Сначала изучи код, потом меняй. Не переписывай работающее, не удаляй существующие механики.
- Новые существа, враги, постройки, ресурсы — это записи в `src/config/*.js` (только данные, без кода).
- Все тексты — в `src/config/i18n.js` сразу на трёх языках: ru, en, ka.
- Сохранения (`src/save/SaveManager.js`): при изменении формата поднимай SAVE_VERSION, старые сохранения должны читаться. Только JSON, никакого eval. Проверяй ключи через `Object.hasOwn`.
- Телефоны важны (портрет 375x812 и горизонталь 740x360): проверяй, что элементы не перекрываются и ничто не закрывает героя (проекция героя на экран против панелей; размеры 375x812, 360x640, 412x915, 740x360). Крупные кнопки, без тяжёлой графики, модели из простых фигур.
- Не добавляй платные сервисы, API-ключи, чат без модерации, сбор личных данных.

## Бюджет производительности (замер на 3 островах, 15.10.2026: 50–100 вызовов отрисовки, 3.5–6 тыс. треугольников за кадр)
- Держи кадр в пределах ~300 вызовов отрисовки и ~50 тыс. треугольников, без текстур и теней.
- Повторно используй геометрию и материалы, много одинаковых объектов — через общие геометрии.
- Перед крупным добавлением в мир измерь: `g.renderer.info.render` (calls, triangles) в консоли браузера.
- Замер скорости на компьютере без видеокарты ничего не говорит про телефон: реальные FPS смотри на устройстве (настройка «Показывать FPS»).

## Проверка перед тем как сказать «готово»
1. `npm run build` проходит без ошибок.
2. Игра запускается (`npm run dev`), в консоли браузера нет ошибок.
3. Затронутые механики проверены, старое сохранение загружается.
Не пиши «готово/исправлено/опубликовано», если не проверил. Прямо говори, что не проверено.

## Работа с Git
- Эксперименты — в отдельной ветке. В `main` попадают только проверенные изменения.
- Перед крупными изменениями — коммит рабочей версии (для отката).

## Игровой дизайн (решения владельца проекта)
- Домашний остров — место развития и прокачки: там спокойно, монстры только рейдами (config/raids.js). Сложные враги и боссы живут на других островах.
- В доме можно прятаться; через стены, деревья и постройки пройти нельзя.

## Структура
`src/core` цикл игры · `world` остров и ресурсы · `player` герой, камера, ввод · `creatures` существа и ИИ ·
`arena` командная арена 5 на 5 · `combat` враги и бой · `building` строительство · `inventory` · `progression` · `ui` · `save` · `config` данные.
